# Integración BMS multisistema

## Resumen

Participación en implementación BMS para una instalación de gran escala, orientada a centralizar monitoreo y control de infraestructura electromecánica.

El sistema permitió integrar variables operacionales de distintas disciplinas para apoyar operación, diagnóstico y mantenimiento.

## Alcance técnico

- Supervisión de sistemas HVAC centralizados.
- Integración de plantas de agua helada.
- Monitoreo de medición eléctrica.
- Monitoreo de almacenamiento de agua.
- Monitoreo de disponibilidad de combustible.
- Integración de alarmas y variables operacionales.

## Función del BMS

El BMS proporciona una plataforma común para visualizar estados, alarmas y variables relevantes de la instalación. Esto reduce la dispersión de información y mejora el seguimiento técnico de sistemas críticos.

## Participación

- Automatización HVAC.
- Integración de equipos.
- Configuración de puntos.
- Monitoreo de variables.
- Configuración de alarmas.
- Pruebas funcionales.
- Verificación de comunicaciones.
- Troubleshooting.
- Puesta en marcha del sistema BMS.

## Valor profesional

Este proyecto refuerza experiencia en supervisión multidisciplinaria, integración de equipos y commissioning de plataformas BMS complejas, manteniendo enfoque en operación y mantenimiento.
