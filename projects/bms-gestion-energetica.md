# Piloto BMS de gestión energética

## Resumen

Proyecto piloto de automatización, monitoreo energético y adquisición de datos para una instalación pública con sistemas HVAC relevantes.

El objetivo fue disponer de información operacional confiable para identificar oportunidades de optimización energética mediante históricos, dashboards y análisis de variables reales.

## Alcance técnico

- Control y monitoreo de manejadoras de aire.
- Monitoreo de flujo y consumo asociado a agua helada.
- Medición eléctrica general de la instalación.
- Adquisición y almacenamiento de variables operacionales.
- Visualización en tiempo real e históricos.
- Acceso remoto mediante conectividad celular.

## Arquitectura general

```text
Sensores / equipos HVAC
-> Controladores BMS
-> BACnet/IP
-> Gateway industrial
-> Procesamiento en Python
-> Servidor remoto
-> Base de datos de series temporales
-> Dashboards de análisis energético
```

## Participación

- Configuración de controladores BMS.
- Desarrollo de lógica de control para manejadoras de aire.
- Integración mediante BACnet/IP.
- Adquisición y procesamiento de datos operacionales.
- Configuración de variables históricas.
- Validación funcional del sistema.
- Troubleshooting de comunicaciones e integración.

## Valor profesional

El proyecto combinó automatización HVAC, IoT, comunicaciones remotas y gestión energética basada en datos. Aporta evidencia de capacidad para transformar operación de campo en información accionable para eficiencia y mantenimiento.
